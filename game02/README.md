# Survivor

一款基于 Phaser 3 的移动端幸存者类游戏（Vampire Survivors-like），使用 TypeScript + Vite 构建。

## 快速开始

```bash
# 安装依赖
bun install

# 启动开发服务器
bun run dev

# 构建生产版本
bun run build

# 预览生产构建
bun run preview
```

打开 `http://localhost:3000` 即可游玩。

## 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Phaser | 3.80+ | 游戏引擎（Arcade Physics） |
| TypeScript | 5.4+ | 类型安全 |
| Vite | 5.4+ | 构建与热更新 |
| Bun | - | 包管理器 |
| Web Audio API | - | 程序化音效生成 |
| i18n | 自研 | 中英双语（默认中文，可切换） |

## 游戏玩法

- **角色选择**：开局从 3 名角色中选择（战士 / 游侠 / 法师），各有专属武器和成长方向
- **移动**：桌面端 WASD 键盘控制，移动端左半屏虚拟摇杆
- **攻击**：自动瞄准并射击最近的敌人
- **升级**：击杀敌人掉落经验球，收集升级后从三个强化中选择一个（含角色专属升级）
- **波次**：每波结束后进入下一波，敌人数量和强度递增
- **阶段（Stage）**：每 5 波进入新阶段，开放新敌人种类和 Boss
- **Boss**：每 5 波出现当前阶段对应的 Boss
- **语言**：支持中文 / English 切换，主菜单可随时切换
- **存档**：每波结束自动存档到 localStorage，下次打开可继续

## 设计说明

- **零外部资产**：所有图形通过 `Graphics.generateTexture()` 程序化生成（每种敌人/Boss 有独特形状），所有音效通过 Web Audio API 合成
- **移动优先**：750×1334 竖屏分辨率，`Scale.FIT` 自适应缩放，虚拟摇杆操控
- **数据驱动**：所有游戏数值由 CSV 配表驱动（`src/data/*.csv`），通过 `csvLoader.ts` 解析为类型化数组
- **场景分离**：HUD 和 LevelUp 作为独立场景叠加运行，与游戏逻辑解耦
- **阶梯难度**：5 阶段关卡系统，每阶段引入新敌人和 Boss，体感难度阶梯式上升
- **角色差异化**：3 角色各有专属起始武器、数值偏向和专属升级，鼓励多周目体验
- **国际化**：自研 i18n 系统，所有玩家可见文本支持中英双语切换
